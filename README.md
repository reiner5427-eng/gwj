# 우리 반 졸업앨범 한마디 💌

26명의 학생을 위한 졸업앨범 한마디 모음입니다. HTML/CSS/JavaScript 화면과 Sites의 D1 공용 저장소를 사용합니다.

## 로컬 사용

`public/index.html`을 더블클릭하면 설치 없이 열립니다. 로컬 모드의 글은 해당 기기·브라우저의 localStorage에만 저장됩니다. 로컬 글을 온라인으로 자동 업로드하지 않습니다.

## 온라인 사용

Sites에서 배포한 주소를 학생들과 공유하세요. 이름과 멘트는 사이트 방문자에게 보이며, 등록 내용은 공용 데이터베이스에 저장됩니다. 30초마다 목록을 갱신하고 새로고침 버튼으로 즉시 불러올 수 있습니다. 검색 엔진에는 색인하지 않도록 설정했습니다. 링크를 가진 방문자는 읽고 작성할 수 있으므로 반 안에서 공유하세요.

수정·삭제 권한은 최초 작성한 브라우저의 무작위 토큰으로 확인합니다. 토큰의 SHA-256 해시만 서버에 저장합니다. 다른 브라우저나 브라우저 저장소 삭제 후에는 기존 글을 수정할 수 없습니다. 이름은 띄어쓰기와 영문 대소문자를 무시해 중복을 막습니다. 동명이인은 이름 옆에 번호를 적어 구분하세요.

## 개발·배포

Node 22.13 이상. 의존성 설치 후 `pnpm dev`, `pnpm build`를 사용합니다. Sites 스킬에 따라 빌드·소스 동기화·게시합니다. `.openai/hosting.json`의 `DB` 바인딩으로 영구 저장소를 연결하며, Drizzle 마이그레이션은 배포 시 적용됩니다.

`GET /api/entries` 목록, `POST` 등록, `PATCH` 수정, `DELETE` 삭제. 수정 요청에는 브라우저 토큰을 `X-Album-Owner` 헤더로 보냅니다. 이름 중복과 26명 제한은 서버에서도 확인합니다.
